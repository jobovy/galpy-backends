# Manuscript: galpy with jax and PyTorch backends

AASTeX 7.0.1 (`aastex701.cls`, `aasjournalv7.bst` included). Build with `make`
(needs `pdflatex -shell-escape` and `pygments` for the `minted` code listings).
Sections live in `sections/`, macros in `macros.tex`, the bibliography in
`refs.bib` (every entry verified; see `notes/BIB_NOTES.md`). Figures are
referenced directly from `../figures/<name>/<name>.pdf`. Working notes used to
write the paper are in `notes/`.
