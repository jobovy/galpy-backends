### turning_point_handling
The fixed lower limit base (umin/umax u-side, vmin v-side) is a turning point where S=0, so the naive Leibniz lower-boundary term -f(base)/sqrt(S(base))*dbase/dc diverges; it exactly cancels the 1/sqrt(S) divergence of the parametric partial-range integrand as u->base (same mechanism as PR-A's action Hessian). Handled by keeping everything in the t^2 substitution u=base+sign*t^2: base appears both as substitution origin AND inside S(u), the 2t Jacobian regularizes, and base carries its TRUE implicit du_tp/dc = -(dS/dP)/S_u at the turning point (c=False _refine_tp Newton-graft; C would recompute calcUminUmax/calcVmin at perturbed IoM, Route B). The v High-panel base=pi/2 is an exact CONSTANT -> no turning term. Verified: the finite combined (base-motion + parametric) matches jax AD to ~1e-9 on generic orbits.

### near_tp_guard
Fires when the current position is within round-off of a panel endpoint: (a) S(pos)->0 (pos -> turning point: boundary factor f(pos)/sqrt(S(pos)) blows up), OR (b) mid=sqrt|pos-base|->0 (pos exactly at a panel base). Coord-space triggers: vR=0 drives ux toward a u-turning point so S_u(ux) shrinks (probe 2: S=4.6e-4, factor ~231, end-to-end residual 5.5e-6 = the near-tp floor); vz=0 shrinks S_v(vx) (S=8.2e-4, still ~6e-7); z=0 drives vx to EXACTLY pi/2 (the v High-panel base) so mid_v=0 -- there the c=False map mid=sqrt|pi/2-vx| has an infinite-slope kink and the AD reference returns NaN (pvx!=0, so not a true turning point), while the C-native closed-form boundary term stays finite/correct. Recommended C guard: when S(pos)<eps or |pos-base|<eps, use the finite analytic boundary term (or zero the angle grad, per the AA turning-point-edge convention).

### partial_range_integrals
Crux 1 — the SAME S^-3/2 regularized integrand family as PR-A's calcd2JR/calcd2Jz, but over the PARTIAL t^2-range [0, mid] (turning point -> ux), mid=sqrt(sign*(ux-base)), NOT the full period. ### turning_point_handling
Crux 3 — the fixed limit `base` (umin/umax for u; vmin for the low-v panel) is a turning point where S=0. Its motion dbase/dc is the _refine_tp implicit derivative = -S_c^expl/S_u |_base. In the t^2 map the base-side boundary term vanishes (the 2t=mid*s Jacobian ->0 at s=0), and the S^-3/2 parameter integral's divergence at base cancels EXACTLY against the base motion: the numerator (Su*u_c + S_c^expl) -> Su,base*dbase/dc + S_c^expl,base = 0, and since u-base = sign*(mid*s)^2 ~ s^2 the numerator is O(s^2), so the S^{3/2}~s^3 denominator with the measure ~s gives a FINITE integrand at s=0. u_c=(1-s^2)*dbase/dc + s^2*dux/dc linearly interpolates base-motion (s=0) and ux-motion (s=1). This mirrors PR-A's H-integrand (Su*uP+SP vanishing at the turning point); no explicit turning-point boundary term is added. High-v panel base=pi/2 is a REGULAR point (S>0, dbase=0), no cancellation needed.

### boundary_evaluation_c
Crux-2 current-position boundary term — the one genuinely new structural term vs the frequency Jacobian. Both derivations agree and independently validated the closed form (deriv A 3.2e-11, indep2 7.9e-9). Upper limit is the CURRENT position (ux/vx), where S>0 finite, so Leibniz gives a non-vanishing term:

  d(P_k)/d(ux) = sign_u * factor_k(ux) / sqrt(S_u(ux))      [contribution to dP via * dux[c]]
  d(Q_k)/d(vx) = sign_v * factor_k(vx) / sqrt(S_v(vx))      [* dvx[c]]

factor_k in {sinh^2(ux), 1, 1/sinh^2(ux)} for (PE,PI,PL) and {sin^2(vx),1,1/sin^2(vx)} for (QE,QI,QL) — i.e. exactly the gv_k the integrands dJRdE/I3/LzStaeckelIntegrand already encode. sign_u/sign_v = the panel sign (+1 Low-from-umin/vmin, -1 High-from-umax/pi2). Compute S_u(ux) via JRStaeckelIntegrandSquared4dJR(ux,p) and S_v(vx) via JzStaeckelIntegrandSquared4dJz(vx,p); OR use the exact identity S_u(ux)=pux^2/(2*delta^2), S_v(vx)=pvx^2/(2*delta^2) (both confirmed to 3e-15) — the identity form is preferable because it ties the near-tp guard directly to |pux|/|pvx| (the documented trigger). In the t^2 form this boundary term is the s=1 endpoint contribution; if you implement calcAnglePartialDeriv via the woven t^2 integrand (deriv A's dPartial, u_c=(1-s^2)*dbase+s^2*dux, dmid=sign*(dux-dbase)/(2*mid)), it is AUTOMATICALLY included and must NOT be added again. If you implement the factored form (separate G[k][P] range scalars + explicit boundary), add B_u[k]=sign_u*factor_k(ux)/sqrt(S_u(ux)) chained onto dux[c]. Recommend the factored form for clarity/reuse of PR-A's dux/dvx chain arrays.

### partial_range_integral_c
Crux-1 partial-range S^{-3/2} integrals = calcd2JR (:1792-1811) / calcd2Jz (:1883-1902) integrand, restricted to the PARTIAL range [base(turning pt), ux] via the t^2 map u=base+sign*t^2, t in [0,mid], mid=sqrt(sign*(ux-base)) — NOT the full period, and NOT calcd2JR's cos-map. Use gsl_integration_glfixed on [0,mid] at order `order` (calcAnglesStaeckel uses order; the value integrals do too — keep order for byte-consistency of the reused value path). Per GL node t (u=base+sign*t^2, s implicitly t/mid), compute S=JRStaeckelIntegrandSquared4dJR(u,p) (skip if S<=0, matching every C integrand), sq=sqrt(S), S15=S*sq, Su=JRStaeckel_dSdu(u,p), and the factor tables gv[3]={sinh2u,1./sinh2u,1.} , gu[3]={2*sh*ch,-2*ch/(sinh2u*sh),0.} (u-side; v-side gv={sin2v,1./sin2v,1.}, gvd={2*sv*cv,-2*cv/(sin2v*sv),0.}), and the parameter-sensitivity SP: u-side SP[3]={sinh2u,-Ld2/sinh2u,-1.} for P in {E,Lz,I3Ut}; v-side SP[4]={sin2v,-Ld2/sin2v,+1.,JzStaeckel_dSdu0(v,p)} for {E,Lz,I3V,u0}. Then, per factor family P0 and per parameter Pk, the partial-range Hessian-like coefficient (mirrors calcd2JR :1808 exactly but over t^2 with the base as the single moving turning point):
   integrand = 2*t*mid * ( gu[P0]*uP/sq - 0.5*gv[P0]*(Su*uP + SP[Pk])/S15 )  +  (dmid-motion for the interior-limit)
   where uP = (1 - (t/mid)^2) * A_base[Pk],  A_base[Pk] = -SP_base[Pk]/Su_base  (the turning-point implicit motion; ux-limit motion is 0 in this fixed-limit sub-integral because the ux boundary is the separate boundary term). Accumulate G[P0][Pk] = sign * Σ w*integrand, times the SAME prefactor family as the values: u-side pref[3]={delta/sqrt2, -Lz/delta/sqrt2, -delta/sqrt2}?? — NO: use the ANGLE prefactors folded at assembly (angle_jac_assembly), i.e. return the RAW dP[k][c] = Σ_Pk G[P0][Pk]*dPk[c] + B[P0]*dux[c] and let calcAngleJacStaeckel apply s_u*(delta/sqrt2) etc. The turning-point cancellation is EXACT and automatic: at t->0, u->base, uP->A_base[Pk], and Su_base*A_base[Pk]+SP_base[Pk] = Su_base*(-SP_base/Su_base)+SP_base = 0, so the (Su*uP+SP)/S15 numerator is O(t^2) against S15~t^3 with measure ~t => finite integrand at the turning point (same mechanism as calcd2JR's (Su*uP+SP)/S^1.5 regularization). GL nodes are interior so t is never exactly 0. High-v panel base=pi/2 is a REGULAR point (S>0): set A_base=0 (dbase=0), no cancellation.

### phi_and_packaging
The C computes anglephi WITHOUT the azimuth — phi is folded in the Python wrapper (actionAngleFreqAngleStaeckel_c :782, and _staeckel_actions_freqs_angles :628 does remainder(anglephi+phi,2pi)).
