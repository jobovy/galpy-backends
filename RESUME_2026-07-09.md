### PR-5 EIGH BLOCKER SOLVED (2026-07-10) — frozen-eigenvector PSD projection
POC (scratchpad/pr5_eigh_poc.py) validated the fix for the eigh-gradient NaN:
```
_, evecs = xp.linalg.eigh(stop_gradient(cov)); evecs = stop_gradient(evecs)
evals_live = sum(evecs^T * swapaxes(cov @ evecs, -1,-2), axis=-1)   # diag(evecs^T cov evecs), differentiable
proj = (evecs * clip(evals_live,0,None)[:,None,:]) @ swapaxes(evecs,-1,-2)
```
- Forward EXACT vs the numpy loop (~1e-15) generic AND near-degenerate.
- Gradient FINITE everywhere (no NaN) — jax==torch. Differentiates through eigenvalue magnitudes (incl. the clip, so clipped noise directions -> 0 grad) with FROZEN eigenvectors; ignores eigenvector ROTATION (documented approximation, dominant effect is eigenvalue scale; Lorentzian-broadened eigh JVP is a possible refinement if evec-rotation grads ever matter). Frozen-structure philosophy, same as PR-4 hyperparameters.
- This is the ONLY stable option — naive `eigh(cov)` in the grad path -> NaN at repeated/clipped-to-0 evals (routine in a smoothed cov series).
PR-5 plan is now de-risked: remove particle coercion (dispatch is_backend_array), xp.stack the offset/cov assembly (no in-place), frozen-evec PSD projection, numpy progenitor added as constant. Adversarial-review focus: the frozen-evec grad approximation + forward byte-vs-numpy.
